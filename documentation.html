Документация Response Match

Синтаксис выражений

Можно использовать:

  • <<full_url>> или <<url>> — полный URL текущей страницы вместе с путём
  • <<path>> — путь URL текущей страницы
  • <<cookie(name)>> — значение cookie
  • <<http(URL).body>> — GET-запрос к указанному URL и тело успешного ответа; например, <<http(bff/profile).body.userType>> берёт поле userType из JSON-ответа /bff/profile текущего сайта
  • Сравнение «Должно быть» — проверка, что значение по пути существует и не пустое

Условия:

  • ==, !=, >, <, >=, <=

Логика:

  • || — «или»
  • && — «и»
