Документация Response Match

Переменные

Создавайте переменные в вкладке «Переменные» для расчёта значений на основе URL, пути, cookie или других переменных.

Пример:

<<test>> = <<path>> == '/' : 1 || <<path>> == '/product' : 2

В этом выражении:

  • <<path>> — текущий путь URL
  • == '/' — условие сравнения
  • : 1 — результат, если условие выполняется
  • || — логическое «или»
  • <<test>> — имя переменной

Синтаксис выражений

Можно использовать:

  • <<url>> — полный URL запроса
  • <<path>> — путь URL
  • <<cookie(name)>> — значение cookie
  • <<variable>> — ссылка на ранее определённую переменную
  • <<json != null>> — проверка, что тело запроса содержит непустой JSON

Условия:

  • ==, !=, >, <, >=, <=

Логика:

  • || — «или»
  • && — «и»

Пример переменной

<<pageType>> = <<path>> == '/' : home || <<path>> == '/product' : product || 404

Если ни одно условие не выполнено, возвращается значение последнего выражения после :.
